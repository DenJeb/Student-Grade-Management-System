# C++ 学生成绩管理系统

一个基于 C++17 的控制台学生成绩管理系统，包含**学生、教师（班主任）、超级管理员**三类用户。数据使用 CSV 文件持久化。

## 功能概览

| 角色 | 主要功能 |
|---|---|
| 学生 | 登录、修改密码、查看个人登录记录；只读查看个人信息；查看单科成绩、总分、平均分、平均绩点；查看班级总分/平均分排名、单科排名 |
| 教师 | 登录、修改密码；查询/模糊检索/编辑所辖班级学生；按班级+科目录入、修改成绩（0–100 校验）；查看班级各科统计、总分/平均分排名（升降序）、单科排名、成绩梯队分布 |
| 超级管理员 | 账号列表、新增账号、批量新增账号、删除账号、禁用/启用账号、重置密码；学生/班级/科目增删改查；全部班级成绩录入与修改；修改自己的密码 |

**权限边界**：

- 学生只能查看自己的数据，不能修改任何业务数据，不能自主注册账号。
- 教师只能操作自己所辖班级（由 `classes.csv` 中的班主任工号决定），不能新增/删除学生，不能管理账号。
- 超级管理员拥有最高权限，可管理全部账号、学生、班级、科目和成绩数据。

## 环境与构建

- 语言标准：C++17
- 界面：Windows 控制台
- 已测试环境：Windows 11 + g++ 16.2.0（MSYS2）

## 菜单一览

### 学生（7 项）

个人信息 / 个人成绩单 / 班级排名 / 单科排名 / 查看登录记录 / 修改密码 / 退出登录

### 教师（10 项）

查询学生 / 编辑学生信息 / 成绩录入 / 成绩修改 / 班级统计 / 排名表 / 单科排名 / 梯队分布 / 修改密码 / 退出登录

### 超级管理员（13 项）

账号列表 / 新增账号 / 批量新增账号 / 删除账号 / 禁用/启用账号 / 重置密码 / 学生信息管理 / 班级管理 / 科目管理 / 成绩录入 / 成绩修改 / 修改密码 / 退出登录

## 推荐使用顺序

1. **管理员**登录，创建学生/教师账号，维护班级（绑定班主任工号）和科目，添加学生档案。
2. **教师**登录，对已录入账号的学生录入或修改成绩。
3. **学生**登录，查看个人成绩、绩点、班级排名和单科排名。

注意：管理员“新增学生”只创建学生档案，登录账号需要在“账号管理”中单独创建；删除学生档案和删除登录账号也是分开的。


## 已知限制

- 控制台界面，密码输入不回显；密码以明文保存在 CSV 中。
- 当前版本无个人/班级报表导出、数据备份与恢复。
- 管理员目前提供成绩录入和修改，没有单独的成绩查询/删除入口；账号管理支持批量新增，暂未提供批量删除/禁用/批量重置。
- 排名和统计为实时计算，不落盘保存。
- 教师信息（`teachers.csv`）暂未在界面展示，班级管理使用教师账号作为班主任工号。
- 程序使用相对路径 `data/`，请从项目根目录运行。
